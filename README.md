Цель проекта получить данные о компаниях и вакансиях с сайта hh.ru, спроектировать таблицы в БД PostgreSQL и загрузить полученные данные в созданные таблицы.

## Установка и использование

Для работы программы необходимо установить зависимости, указанные в файле `requirements.txt`

```
pip install -r requirements.txt
```

Для работы с базой данных необходимо создать файл `.env` с параметрами доступа к базе данных PostgresSQL. Пример содержимого файла:

```
POSTGRES_HOST=localhost
POSTGRES_USER=postgres
POSTGRES_PASSWORD=password
POSTGRES_PORT=5432

```

## Описание файлов

- `main.py` содержит функцию `main` для запуска приложения
- `APIhh.py` содержит класс APIhh для получения данных о компаниях и вакансия с сайта hh.ru.
    В классе реализованы методы сбора информации о компаниях и вакансиях.
- `DBWorker` содержит класс DBWorker для подключения к базе данных PostgresSQL.
    В классе реализованы методы создания БД, создания таблиц и заполнения таблиц.
- `DBManager` содержит класс DBManager для работы с базой данных PostgresSQL.
    В классе реализованы методы для подключения к БД и взаимодействия с таблицами.
- `user_interface.py` содержит функцию для взаимодействия с пользователем.
- `config.py` вспомогательный модуль, содержит класс Config для работы с данными файла .env.
- `read_from_file.py` вспомогательный модуль для чтения данных из файла companies.txt и последующего использования в классе APIhh.
